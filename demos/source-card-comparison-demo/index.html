Architecture comparison

One reference, two component boundaries

Both columns render the same bilingual text. The difference is not the pixels: it is which component owns the reference header and whether the text is modeled as one special segment or as a one-item collection.

Current PR #42 shape

Host header + bilingual segment

The host owns the reference label. The element owns exactly one aligned pair and carries the range-level reference on that pair.

Proposed expanded shape

One source card with a singleton item array

The card owns the reference header and an ordered collection. This single reference is represented by items: [pair].

  • <sefaria-source-card> → header + items[]
  • shared renderer → pair markup/CSS
  • range → same component, more positional items
