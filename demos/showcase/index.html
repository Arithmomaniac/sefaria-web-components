Reference changes call the existing async factory. Theme, font, and viewport changes are presentation-only and do not refetch.

Stateful readers come ready-made

Supply a starting reference and client. The controller retains history, loads connections, and keeps the request-free Reader current.

The supported factory returns after the initial source and connections settle. The persistent Reader emits actions; the controller owns continuing navigation and cancellation.

Compose the interaction you need

Lower-level hosts can theme square, flush panels and repeat the spatial cycle: select a source, open its connections, follow a reference into contextual text, and continue from the newly selected segment.

This is deliberately not the composite Reader. The host owns pane placement and descendant pruning while request-free source and connections components continue the interaction across new panes.

A Sefaria reading surface, wherever you read

The Linker turns citations in an ordinary article into a contextual Sefaria surface, using the same request-free popup without taking over the host page.

The classic script owns explicit detection and polling. The popup still receives only its view model.

The same Reader UI, delivered as an MCP App

A tool result can deliver the same stateful Reader inside a compatible host. Navigation stays in the App through host-proxied tools; chat export remains an explicit action.
