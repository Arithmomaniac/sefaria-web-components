# Sefaria Web Components has moved

Active development, maintained documentation, and browser examples now live in [Sefaria Frontend Toolkit](https://github.com/Arithmomaniac/sefaria-frontend-toolkit). Use the [published documentation and examples](https://arithmomaniac.github.io/sefaria-frontend-toolkit/) for the current project.

This repository is retained as a read-only archive of the Microsoft Global Hackathon 2026 work. Its existing history and source remain available for reference, but new changes should be made in the maintained repository.

> **Experimental.** This project has no support or stability guarantee. It is not an official Sefaria product. Packages from this repository were private workspace packages, not a published installation offering.
