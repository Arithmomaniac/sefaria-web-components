# Vanilla Vite example

This private example exercises the public client, source-card factory, and custom-element registration paths with a deterministic validated response for `Micah 6:8`. The injected `fetch` keeps the ordinary build and smoke test offline from Sefaria; it does not change the client or element request-ownership contracts.

From the repository root, run `pnpm --filter @sefaria-example/vanilla-vite dev` for development or `pnpm --filter @sefaria-example/vanilla-vite build` for a production bundle.
