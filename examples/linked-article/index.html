Justice, mercy, and an authored source link

An ordinary article can keep its native links while adding a request-free Sefaria source preview.

The prophet's compact instruction in Micah 6:8 joins public justice, steadfast kindness, and humility. The citation is an authored anchor first: it still navigates when scripts are unavailable, and this page enhances only an ordinary unmodified activation.

הִגִּיד לְךָ אָדָם מַה טּוֹב וּמָה יְהוָה דּוֹרֵשׁ מִמְּךָ כִּי אִם עֲשׂוֹת מִשְׁפָּט וְאַהֲבַת חֶסֶד וְהַצְנֵעַ לֶכֶת עִם אֱלֹהֶיךָ׃

Authors decide where citations belong, what text readers see, and which native destination remains available. The enhancement does not inspect prose, infer references, rewrite the article, or install a global script API.

What the page owns

The page creates the client, calls the public popup factory, cancels obsolete work, rejects stale results, and removes its listeners on cleanup. The Web Component receives only its view model, anchor, and open state.
